## Descripción General

Este repositorio contiene un conjunto de prácticas académicas desarrolladas durante la materia de **Extracción del Conocimiento de Bases de Datos**, enfocadas en la aplicación de técnicas de limpieza, exploración, análisis y visualización de datos utilizando datasets reales.

A lo largo de las prácticas se emplearon herramientas de análisis de datos para transformar información en conocimiento útil mediante la aplicación del modelo **DIKW (Data, Information, Knowledge, Wisdom)**.

---

## Objetivo

Desarrollar habilidades para la extracción de conocimiento a partir de bases de datos mediante:

* Limpieza y preparación de datos.
* Análisis descriptivo de información.
* Generación de visualizaciones estadísticas.
* Interpretación de resultados.
* Aplicación del modelo DIKW.
* Uso de herramientas de ciencia de datos.
* Gestión y documentación de proyectos mediante GitHub.

---

## Datasets Utilizados

### 1. dataset_sucio_practica.csv

Dataset utilizado para realizar procesos de limpieza y preparación de datos, identificando y corrigiendo valores faltantes, inconsistencias y registros duplicados.

### 2. netflix_titles.csv

Dataset que contiene información sobre películas y series disponibles en Netflix, utilizado para análisis exploratorio y visualización de datos.

### 3. test.csv

Dataset empleado para pruebas de transformación, exploración y análisis estadístico.

### 4. ventas-por-factura.csv

Dataset utilizado para analizar información de ventas, identificar patrones comerciales y generar conocimiento a partir de indicadores relevantes.

## Metodología Aplicada (Modelo DIKW)

### Datos (Data)

Obtención de información cruda proveniente de los datasets.

### Información (Information)

Procesamiento y organización de los datos mediante técnicas de limpieza y transformación.

### Conocimiento (Knowledge)

Identificación de patrones, tendencias y comportamientos mediante análisis estadísticos y visualizaciones.

### Sabiduría (Wisdom)

Interpretación de los resultados obtenidos para apoyar la toma de decisiones y generar conclusiones útiles.
